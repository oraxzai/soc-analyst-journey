## 📸 Evidence Standard

Every investigation in this portfolio includes:

- ✅ **Redacted screenshots** (no client data, no secrets)
- ✅ **Structured triage logs** with verdicts + reasoning
- ✅ **MITRE ATT&CK mappings** for every alert
- ✅ **IOC extraction** with proper type classification
- ✅ **Lessons learned** sections

See [templates/screenshot-guide.md](./templates/screenshot-guide.md) for the documentation standard.
